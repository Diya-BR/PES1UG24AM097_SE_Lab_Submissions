# Lab 2: Agile Backlog Creation & Sprint Simulation in Jira

## Objective

Convert the functional requirements identified in Lab 1 into an Agile backlog, estimate and prioritize the work, and simulate a sprint using Jira.

## Activities

- Create Epics and related User Stories based on the Lab 1 requirements.
- Write User Stories using the format: “As a [user role], I want [goal], so that [benefit].”
- Prioritize backlog items according to business value and user needs.
- Assign Story Points using the Fibonacci sequence and use Planning Poker as the estimation approach.
- Create Sprint 1, select backlog items, and move work through **To Do → In Progress → Done**.
- Review the sprint Burndown Chart and reflect on the sprint outcome.

## Deliverables

- Screenshot of the Jira backlog containing Epics and User Stories.
- Screenshot showing Story Point assignments.
- Screenshot of the Active Sprint board.
- Screenshot of the Burndown Chart.
- Brief document answering the lab reflection questions.

## Tools

- Jira
- Agile backlog and sprint-planning practices
