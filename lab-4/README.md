## Changes Implemented

The game repository includes the requested Lunar Lander improvements:

1. Check horizontal touchdown speed in addition to vertical speed and landing angle.
2. Change the ship colour based on the remaining fuel ratio.
3. Display a landing effect when the ship lands.
4. Award an extra life when the score reaches the configured threshold.
